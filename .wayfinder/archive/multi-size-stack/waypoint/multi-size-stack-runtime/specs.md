# 多尺寸固定栈端到端支持 · 规格

## 要求与场景
请求/可用大小单位均为字节；P 表示实测系统页大小，U 为向上按 P 对齐后的可用大小，保护页不计入 U。下列为新增/保持的目标行为，不表示当前已实现。

### R1 默认与显式选择
省略大小从启动前的全局配置取得默认；显式指定不得改写全局配置或影响后续默认调用。显式 0 为非法，不是默认哨兵。
- **S1** 前置：启动前设置一个非原始默认值；动作：同一运行时交错注册默认、显式及带描述/成功输出的任务；结果：每项报告各自 U，默认配置不变，旧宏/重载不歧义。另用不启动 runtime 的默认配置测试锁住出厂 12 KiB 对应 U。

### R2 对齐与保护
正的有效请求向上页对齐，内存起点页对齐；保护开关是栈自身属性。开启时多分配一个低地址保护页，可用区不变；关闭时不额外分配保护页。
- **S2** 前置：正常页大小；动作：申请 1、P-1、P、P+1、12 KiB、16 KiB+1、64 KiB；结果：U≥请求、U%P=0、U-请求<P，分配起点%P=0，protected 的总量=U+P、unprotected=U。小值只测内存布局，不在极小栈执行测试框架。
- **S3** 前置：在尚未启动线程的独立子进程中构造保护/无保护栈；动作：访问保护页或无保护栈的对应首地址；结果：前者子进程收到 SIGSEGV，后者正常；父进程检查 wait 状态，不能只看属性字段。正常可用区末端可写，保护页不属于登记的可用区。

### R3 同一运行时多尺寸固定栈
不同大小可共存、挂起和恢复，栈大小在创建后固定，不以任务切换或当前默认配置重新计算。
- **S4** 前置：一个只初始化一次的 runtime；动作：注册数种充足大小的协程，让它们通过有界等待真实挂起/唤醒；结果：挂起前后查询值分别稳定，局部数据未污染，全部在超时内完成。断言在控制线程做，不向小栈塞 Boost.Test 或日志重载。

### R4 按实际属性精确复用
只从相同 U 且相同保护属性的缓存取栈；相同归一化大小可复用；较大桶也不隐式替代较小桶。归还使用栈自身属性，不再读取全局大小/保护开关。
- **S5** 前置：无其他借出者的局部池；动作：交错借还多个不同 U，随后对其中一个仅保留单个缓存栈的桶再次申请；结果：正确桶复用该 Stack 对象/地址，其他尺寸不串桶，实际可用大小严格等于对应 U。
- **S6** 前置：同 U 的有保护和无保护栈同时借出；动作：交错归还再申请，及用两个对齐后相同的不同请求申请；结果：保护属性不串桶、相同 U/属性可复用。全局配置变更仅在没有 runtime/其他线程的隔离测试用于证明归还不依赖默认值，不宣称运行期改配置受支持。

### R5 全池容量与计数
最大数约束跨桶的同时借出＋已预留申请，不是每桶上限或内存字节预算；容量检查与预留原子完成。缓存仍属池分配数，空闲、借出、申请中分别准确计数；平均数和最低保留数全池统一。
- **S7** 前置：启动前设小上限，局部池/线程同步屏障；动作：让超出上限的多线程同时申请不同尺寸，成功者持有到第二屏障；结果：成功总数不超上限，失败可观察，释放后计数回零且可再次申请，无单桶乘法放大。
- **S8** 前置：多线程混合借还及一个执行回收的线程；动作：有界迭代并持续检查属性，保留部分借出栈跨过回收；结果：借出栈未被销毁、不重复借出同一对象，计数不下溢，最终回零；分配数等于实际缓存/借出管理对象，不借近似队列长度推导。

### R6 非法值及失败安全
Debug/Release 均进行运行时检查。零值抛 invalid_argument；页取整、追加保护页、指针差可表示范围超限抛 length_error；内存不足抛 bad_alloc；建立保护失败抛带 errno 的 system_error。低层池容量不足返回空，创建/注册抛 runtime_error；成功输出重载不抛并置 false。所有可恢复失败不发布半成品、泄漏栈或残留容量预留。
- **S9** 前置：故障未注入、系统状态正常；动作：输入 0、SIZE_MAX、取整/保护页加法越界及大于 PTRDIFF_MAX 的值，通过直接构造/创建/显式注册及成功输出入口测试；结果：在分配/指针运算前拒绝、异常类别符合契约、回调不执行、全局默认及池计数不变。负的旧 signed 调用转换后也必须被范围检查拒绝，不静默变小。
- **S10** 前置：只在测试构建中启用窄范围一次性故障注入；动作：使内存申请、建立保护、缓存入队分别失败，并验证 callable/描述构造及发布前的所有权清理；结果：前两类错误返回规定异常、预留回滚，缓存入队失败则销毁栈并更新计数、不从析构抛异常；后续申请成功。借出上限/无 worker 的注册失败也不留对象。注入失败与真实 OS 失败分开表述，不能用 mock 代替正常路径真实分配/调度。

### R7 预热、回收与资源生命周期
预热只针对默认 U/保护桶，实际创建 min(预热数量,全池上限) 个不同栈，不能循环复用同一栈冒充预热。定时回收按全池平均/最低数策略只回收空闲；显式清空缓存遍历所有桶，即使仍有借出者也不销毁借出栈。空桶目录仅在无缓存/借出/预留时可清除。
- **S11** 前置：runtime 未启动，预热数与上限受控；动作：构造局部池，连续借出预热数个默认栈；结果：对象互不相同、成功数/初始分配数准确、其他桶无复制预热；构造期间失败安全清理已创建栈且错误可观察。
- **S12** 前置：数种尺寸缓存和一个持有的借出栈；动作：清空空闲、使用借出栈、归还再清空；结果：第一次只释放空闲且借出仍有效，最终分配及借出计数为零；默认最低数不限制显式清缓存。定时回收的总保留目标为 max(全池最低数,平均目标)，不为每桶复制最低数。
- **S13** 前置：运行真实正常释放路径；动作：移动 Stack、重复 Clear，及销毁持有唯一回调捕获对象的 Context；结果：所有权/Valgrind 登记转移、Clear 幂等，回调捕获析构观察发生在栈归还之前，归还后计数恢复。解除保护失败属于不可安全 free 的系统故障：在隔离故障子进程中可观察 fail-stop，并区分确实进入 terminate、普通返回和无关崩溃，不抛出析构、不冒险继续 free；不能将其说成可恢复成功。

### R8 兼容与交付证据
保持 C++17、默认宏/注册接口、单进程寿命和单次初始化；接通原来被忽略的显式小值是行为修复而非完全不变。detail ABI 重编要求须告知；CoPool 的栈属于 worker 协程，不支持同一 worker 按任务换栈。
- **S14** 前置：所有旧直接创建调用和公开说明已核查；动作：编译默认宏/描述/成功输出及新重载的真实调用，运行直接耦合测试；结果：无重载歧义、旧重型小栈 fixture 已有明确大小依据，无新编译警告；说明默认 12 KiB、字节/保护/错误/重编与 CoPool 边界一致。
- **S15** 前置：当前候选；动作：Debug/Release 冒烟＋功能＋直接耦合、profile/stringent-debug/生产编译及适用 Valgrind；結果：绑定确切候选、命令/退出码和实际用例，无空集假阳性；环境缺失及未测保留缺口。Release 测试重点确认库在 NDEBUG 下仍实际拒绝非法值、兑现失败返回/异常与释放；仅日志或表达式被求值不算通过。生产无测试注入须有结构与实际产物的证据，不以编译成功替代。
- **S16** 前置：最终候选及远端动作获得授权；动作：独立审查、CI 全量 CTest/required checks、既有快速性能回归；结果：证据绑定当前候选，阻断修复复核；pending/WARN/NO_COMPARABLE_BASELINE 不冒充通过，未满足实施出口不标 done。本轮 plan 只评审计划，不执行这些检查。

## 约束与不变项
- 未指定从配置选择；默认 12 KiB 不变，保护默认开启，不允许运行期修改配置作为选栈机制。显式大小必须贯通，不以 0 或二次幂档替代约定。
- 继续有栈协程、memalign+mprotect、低地址逐栈保护及只登记可用区；不改变 ASIO 边界、进程寿命、初始化次数或线程/调度器数量。
- 不引入伙伴系统、扩/换栈、CoPool 改造、新依赖/通用分配器、内存字节预算配置、平台推广或发布流程。
- 本地不跑全量测试；完整远端门禁保持。所有真实实施及外部写入另核授权，ready/任务勾选/CLI 结构结果均不是完成证据。
