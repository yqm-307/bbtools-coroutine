# AI 产物治理实施计划

> **面向 AI 代理的工作者：** 本计划用于在当前仓库中更新 `AGENTS.md`。步骤使用复选框（`- [ ]`）跟踪进度。

**目标：** 为仓库 AI 增加简洁、工具无关的有意义产物治理规则。

**架构：** 在现有 `AGENTS.md` 增加一个独立章节，定义长期资产、阶段性交付证据和原始运行产物三类规则，并补充收尾时的去重检查。保持现有代码、测试、OpenSpec 和工具配置边界不变。

**技术栈：** Markdown、Git、现有仓库文档结构。

---

## 文件边界

- 修改：`AGENTS.md`，新增“AI 产物治理”章节。
- 不修改：`.gitignore`、现有报告、`.kilo/plans/`、`openspec/` 其他文件。

## 实施步骤

### 任务 1：加入 AI 产物治理规则

- [x] 在 `AGENTS.md` 的现有工作流或完成条件附近加入三类产物规则：
  - 长期资产必须追踪并提交；
  - 阶段性交付证据仅在有重要结论、风险、未覆盖范围或复核价值时简短记录并提交；
  - 原始日志、采样、构建输出、缓存和工具会话不提交。
- [x] 明确 AI 不绑定特定工具、prompt 或目录；先检查现有文档和 `.gitignore`，优先更新权威文档。
- [x] 明确收尾必须检查重复、过期和冲突产物；修订或合并可自主执行，删除、移动和修改历史链接需确认。
- [x] 明确最终汇报简要说明产物新增、更新、合并情况；无产出时说明原因。

### 任务 2：验证规则与变更范围

- [x] 检查章节与现有 AGENTS 规则无冲突，确认没有引入固定目录或工具依赖。
- [x] 查看 `git diff --check` 和 `git diff -- AGENTS.md`，确认只修改目标文件。
- [x] 运行 `git status --short`，确认没有意外文件变更。
