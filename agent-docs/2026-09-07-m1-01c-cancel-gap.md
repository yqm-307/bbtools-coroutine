# M1-01c 协作式取消：实现与契约差异

契约真源：`agent-docs/2026-09-07-core-runtime-contract.md`
Issue：#266

## 已锁住

- `RequestCancel()` 只置位，不杀运行中的用户代码
- 等待中（`YieldUntilTimeout` 等）会被 `Trigger` 唤醒
- 运行中在 `IsCancelRequested()` / `bbtco_yield` 检查点自行退出
- 退出走普通 C++ 栈展开，RAII 析构会跑
- 取消不是异常，也不是新的 `CoroutineStatus`

## 缺口

- 无按 ID 取消、无公开 Task 句柄（detached 仍要自己拿 `g_bbt_tls_coroutine_co`）
- 纯 `Yield()`（MANUAL、不入队）不会被取消唤醒
- 等待返回值仍是 0/-1/1，用 flag 区分 Cancelled；独立 `Cancelled` 码留给后续
- 入口 `IsCancelRequested` 与挂事件之间的窗口：`_RegistAwaitEvent` 注册前会再 Trigger 一次
